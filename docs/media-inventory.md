## Integration notes

- Use the JPEG social replacement for `og:image`, `twitter:image`, and schema unless target-platform compatibility is explicitly verified for WebP or AVIF.
- The current hero is a CSS background. A future CSS update can use `image-set()` with AVIF/WebP and media-specific widths, plus a preload for the selected above-the-fold candidate.
- Use AVIF/WebP `<picture>` sources for the about gallery with the retained JPEG originals as fallbacks.
- Use the 160×160 profile derivatives rather than downloading the large PNG sources for 32–38 pixel avatars.
- Keep source captures until every live reference has migrated and visual regression checks pass.
