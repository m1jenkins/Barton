# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- Use Node 24 and the checks in `package.json` / `.github/workflows/checks.yml`.
- Read `README.md` first: it maps every folder, the two page styles (current `buying/*.css` vs legacy `styles.css`), and which folders are not deployed. `docs/README.md` indexes the docs.
- Root `*.html` files are live URLs; each page carries its own copy of the header, footer and nav. Do not rename or move them without a `vercel.json` redirect.
- Public copy uses “car search” or “search details”; never use “brief” (including metadata, accessibility labels, dynamic messages, and downloads).
- Read `.ai_rules` before UI changes (`.cursorrules` is a symlink to it).
- Homepage CSS/JS URLs use content hashes to avoid stale live caches; `scripts/validate-site.mjs` checks them and reports the required URLs after asset changes.
- The owner approved all current website content on October 1, 2026; see `docs/content-approval-2026-10-01.md`. Do not add draft warnings or require another content verification/approval for existing website copy.
- Metro generation and release records: `docs/metro-execution-2026-09-16.md`, `data/metro-release.json`, and `docs/release-readiness.md`. Draft generation is local-only. Editing a pinned legacy Texas page also means updating its `legacyTexas[].sha256`, or `scripts/validate-site.mjs` fails.
- Brand search after the October 30, 2026 rename: `docs/seo/2026-11-07-brand-search-visibility.md`. `Organization.sameAs` must match `data/entities.json` (validator and tests enforce it). Run `npm run indexnow` after deploying public page changes.
- Redirects: `vercel.json` plus `scripts/check-redirects.mjs` (`--config-only` for the file, env vars for the live matrix). Apex → www status is host/dashboard configuration that runs before repo routing; see `docs/seo/2026-09-21-claim-safety-redirects.md`.
- `tesla-fsd-for-sale.html` is a keep-noindex park (2026-09-22): real page, `noindex, follow`, self-canonical, off sitemap; do not 301, 410, or index it without a later named Mason decision. See `docs/seo/2026-09-22-tesla-fsd-disposition.md`.
- Competitor comparison pages (`compare-car-buying-services.html`, `caredge-alternatives.html`, `delivrd-alternatives.html`, `used-car-buying-service.html`, `is-caredge-concierge-worth-it.html`, `delivrd-review.html`, `car-negotiation-service.html`, `car-buying-service-cost.html`): every outside link needs a dated `CMP-*` row in `data/source-registry.csv` (a test enforces it); recheck competitor facts on the schedule in `docs/seo/2026-10-18-competitor-comparison-pages.md`.
- Paid intakes (`/api/onboarding`) are emailed to Mason through Zoho SMTP via `intake_email_outbox`; see "Paid intake email" in `docs/implementation-operations.md`. New tables need their `db/*.sql` migration applied to Neon (`barton-checkout-db`) before the code that writes them deploys.
- Car searches are run by hand: Mason runs the `/car-search <intake ID>` skill (`.claude/skills/car-search/`) in Claude Code on his Max plan, and it submits through `/api/car-search`. Do not automate it with his subscription login (Anthropic's terms). Dealer email then goes to Grokbot: `node scripts/car-search.mjs handoff` posts the deal to its webhook, and it emails dealers from a dealer-only Gmail inbox, sending only what Mason approves. Grokbot also queries Neon directly as the database owner, buyer data included (Mason's call, November 3, 2026), and its rules let it write only to `deal_events`. Renaming or dropping intake or deal columns breaks its queries, so update step 11 of `docs/dealer-bot-setup-2026-11-03.md` with any such change. Dealer emails sign off "Mason", never mention Steer Me Right, and carry no buyer contact details. See "Car search" in `docs/implementation-operations.md`.
- Website inquiries (`/api/leads`) are answered by Grokbot's separate Client Outreach assistant (November 3, 2026). Each new lead emails a `New lead <id>` notice to `LEAD_NOTIFY_EMAIL` through the Zoho intake SMTP via `lead_email_outbox` (`db/009`), which wakes it to read the lead from Neon. It replies as `mason@steermeright.com`, through a Gmail relay that sends via Zoho SMTP, only after Mason's tap. The Web3Forms email still reaches Mason, and `LEAD_FORWARD_URL` stays unset, since setting it turns that email off. Changing the notice subject or the `leads` or `onboarding_submissions` columns its prompts query means updating `docs/client-inquiries-setup-2026-11-03.md` and re-sending the prompts. Keep its inbox address, the relay's address and customer details out of this public repository.
- Resources: `docs/resource-release-2026-10-04.md` records the three indexable guides and `compare-car-quotes.html`. The worksheet shares `buying/quote-worksheet.js` with its private preview and intentionally loads no GTM or analytics. Outbox cron/measurement setup and remaining account dependencies are in `docs/implementation-operations.md`.
