## Steps

1. **Workspace.** In [the container](https://tagmanager.google.com/#/container/accounts/6349220223/containers/249056149/workspaces), create the workspace **Google Ads purchase tracking**, then confirm Version 6 is still the live version. If it isn't, stop and re-read the live version first.
2. **Import.** Admin → **Import Container** → choose `gtm-import-merge.json` → workspace **Google Ads purchase tracking** → **Merge** → **Rename conflicting tags, triggers and variables**.
   - The preview should show 2 new tags, 5 new triggers and 7 new variables, with **nothing modified or deleted**. If anything shows as modified or deleted, cancel.
   - Built-in variables Event, Page URL, Page Hostname and Page Path are switched on if they aren't already.
3. **Call Button:**
   - set **Conversion Label** to `AmVzCKThx4gdEN_eiKlD` (Phone click);
   - remove its click-text trigger and add **CE – phone_click**.
   - Don't add a second phone tag, or clicks count twice.
4. **Google tag** (`AW-18071301983`) → **Configuration settings** → add parameter `page_location`, value `{{Page URL – sanitized}}`.
5. **Pause** Book Appointment, Schedule Free Call and Submit Lead Form: open each → ⋮ → **Pause**. Don't delete them; remove the tags after 30 days of no fires, as §2 says.
6. **Consent defaults.** Add the Community Template Gallery template **Consent Mode (Google tags)** (by gtm-templates-simo-ahava). Create two tags from it, both with Command **Default**, all regions, and no `wait_for_update`:

   | Tag name | ad_storage | analytics_storage | ad_user_data | ad_personalization | Trigger |
   |---|---|---|---|---|---|
   | Consent default – GPC on | granted | granted | **denied** | **denied** | Consent Init – GPC on |
   | Consent default – standard | granted | granted | granted | granted | Consent Init – GPC off |

   Whether GPC should also deny `ad_storage` is an owner or legal decision (§3); both tables leave it granted.

   Optional, from [PR #86](https://github.com/m1jenkins/Barton/pull/86), which isn't merged: an exception trigger on the Clarity tag, Page Path matches regex `^/payment-success[^/]*\.html$`.

## Check before publishing (Preview)

1. **Preview on a Vercel preview deployment** with Stripe in test mode.
   - Both conversion tags must show **Not fired**, because of the hostname condition.
   - Every DLV must be filled on the `begin_checkout` and `purchase_verified` events.
2. **Preview on production** (`https://www.driverightcarbuying.com`), without paying:
   - Start checkout on `/car-buying-service.html` and on `/schedule.html`.
   - **Google Ads – Begin checkout** must fire once, with `checkout_attempt_id` as the transaction ID, before the Stripe redirect.
   - On Sep 27 production logged `api_configuration_error: New checkout is paused for cutover` on `/api/checkout-start`. If checkout is still paused, `begin_checkout` can't fire. Record that and test it after cutover.
3. **Tel link:** click a `tel:` link. **Call Button** fires once on **CE – phone_click**.
4. **Chat form:** submit the homepage chat form. No Google Ads conversion tag fires.
5. **Payment page:** in Tag Assistant, open `/payment-success-fullservice.html?session_id=cs_test_probe`.
   - Check that no Google request (`dl`, `url`, `page_location`) contains `cs_test_probe`.
   - Otherwise, log it in `../change-log.md`; per [PR #86](https://github.com/m1jenkins/Barton/pull/86), GTM's own `ccm/collect` page view needs the code fix.
6. **Consent:** in the Consent tab of Tag Assistant, the defaults are set at Consent Initialization.
   - With GPC on (Brave, or Firefox with GPC on), `ad_user_data` and `ad_personalization` are denied.
